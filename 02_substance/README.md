## How to use these documents

- They are the single source the website, one-pagers, and briefings draw from, so the story stays the same everywhere.
- Before any external use, re-run `pm-fact-guardrails` on the file: the facts move, and each doc's source block states when its claims were last searched.
- Every doc carries internal honesty guardrails. If copy cannot pass its own guardrails, the copy is wrong, not the guardrails.
- Lint any edit with `../04_tools/voice_lint.py` before it ships. No em dashes, attribute or label every figure, one idea per sentence.
