# Governance

| Decision | Who decides |
|---|---|
| A report becomes an issue | Claude Code in triage, or a maintainer |
| A pull request merges | A maintainer, or the orchestrating Claude Code session, after `voice-check`, `secret scan` and `DCO` pass ([`CONTRIBUTING.md`](CONTRIBUTING.md)) |
| A fact is right | Its cited source; a correction needs a better one |
| Brand and vision | The founder, as the locked record in [`01_doctrine/brand_identity.md`](01_doctrine/brand_identity.md) holds |
| The gates, the license, these rules | A maintainer, by pull request |

Colorado Startups owns the project. Claude Code runs its day-to-day triage and review under [`AGENTS.md`](AGENTS.md). People hold the seats in [`MAINTAINERS.md`](MAINTAINERS.md).

## The maintainer seat

| Question | Rule |
|---|---|
| Who may ask | A contributor with five merged pull requests over three months who keeps the code of conduct |
| Who decides | Colorado Startups |
| What the seat can do | Review and merge pull requests; turn reports into issues; welcome new contributors |
| What stays Colorado Startups' | The brand, the gates, repository settings and the Pages deploy |
| How it ends | Stepping down at any time, or six months with no review; Colorado Startups can end it |

Every seat is held by a person. AI agents never hold one and never approve a pull request.
